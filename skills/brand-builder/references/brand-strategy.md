# Brand Strategy Reference

## Brand Essence Framework

The brand essence is a single sentence that captures the soul of the company. Structure:

```
[BRAND] [verb: enables/orchestrates/delivers/builds/transforms]
[what they do in specific terms]
so that [target audience] can [outcome they care about].
```

Example: "STROMY orchestrates AI-powered intelligence workflows so knowledge-intensive businesses can operate with the precision of a world-class ensemble."

The verb should match the brand personality — "orchestrates" for a precise brand, "unleashes" for a bold one, "cultivates" for an organic one.

## Positioning Statement

Internal-facing, never published. Structure:

```
For [target audience with specificity],
[BRAND] is the [category/type of company]
that [key differentiator] —
delivering [concrete value proposition].
```

## Tagline Development

Generate 4-5 tagline options across different strategic directions:

| Direction | Strategy | Example pattern |
|-----------|----------|-----------------|
| Functional | Describes what you do | "Intelligence, Orchestrated." |
| Aspirational | Describes the outcome | "Conduct Your Edge." |
| Descriptive | Names the value | "Engineered Clarity." |
| Positional | Claims territory | "Where Process Meets Precision." |
| Provocative | Challenges the status quo | "Stop Guessing. Start Knowing." |

**Tagline rules:**
- Maximum 4 words (ideally 2-3)
- Must work as a standalone phrase
- Should translate well if brand operates multilingually
- Avoid cliches: "innovative solutions", "next-level", "reimagining"
- Test: could a competitor use this tagline? If yes, it's too generic.

## Brand Personality

Select exactly 5 traits. Each should be:
- An adjective, not a noun
- Specific, not generic ("unflinching" not "strong")
- Differentiating — at least 2 traits that competitors wouldn't claim

### Trait banks by industry

**Professional services / B2B:**
Precise, Authoritative, Resourceful, Unflinching, Grounded, Deliberate, Rigorous, Pragmatic, Incisive, Dependable

**Technology / SaaS:**
Inventive, Agile, Transparent, Empowering, Relentless, Elegant, Systematic, Forward-thinking, Resilient, Adaptive

**Creative / Design:**
Expressive, Restless, Refined, Provocative, Intentional, Layered, Visceral, Curated, Uncompromising, Fluid

**Finance / Legal:**
Disciplined, Principled, Measured, Resolute, Discreet, Commanding, Prudent, Exacting, Steadfast, Clear-eyed

## Voice Guidelines

Structure voice rules as imperatives with examples:

```
Write like [analogy — who is this person?].
[3-5 specific rules with rationale]
```

### Voice rule patterns

| Rule | Good for | Example |
|------|----------|---------|
| "Conclusions first" | Analytical brands | Lead with the answer, then support |
| "Short sentences" | Authoritative brands | Never more than 20 words per sentence |
| "Numbers over adjectives" | Data-driven brands | "23 clusters" not "many groups" |
| "Active voice only" | Action-oriented brands | "We analyzed" not "An analysis was conducted" |
| "No jargon theater" | Trust-focused brands | Name the tool, not the buzzword |
| "Questions welcome" | Approachable brands | "Not sure? Let's figure it out together." |

## Do/Don't Pairs

Always provide 2-3 do/don't pairs showing the voice in action. Write them as if they're real copy the brand would publish — not abstract descriptions.

Structure:
```
DO:   [Example of brand voice done right — specific, with industry context]
DON'T: [Same message written in the wrong voice — generic, buzzwordy, or off-brand]
```
